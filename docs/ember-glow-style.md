# Задача: приложи стила „Ember Glow“ към съществуващия сайт

## Цел
Смени **само визуалния слой** на сайта. Не променяй структурата, маршрутите, съдържанието, текстовете, логиката и данните. Всяка страница и секция остава на мястото си, с нова визия.

## Как да работиш
1. **Първо анализирай проекта и не пиши код.** Определи стека (чист CSS, Tailwind, CSS Modules, styled-components, UI библиотека и т.н.), къде живеят глобалните стилове и кои са всички компоненти и секции.
2. **Направи инвентар** (таблица „съществуващ елемент → Ember Glow модел“ по раздела „Карта на компонентите“ по-долу) и ми го покажи преди да продължиш.
3. Прилагай на етапи, в реда от раздела „Ред на прилагане“. След всеки етап пусни dev сървъра или билда и провери, че нищо не е счупено.
4. Ако проектът вече има собствени цветови/тематични променливи (`--primary`, `--background`, Tailwind `colors`, тема на UI библиотека), **пренасочи ги** към новите токени, вместо да подменяш стойности навсякъде.
5. Не добавяй нови зависимости освен шрифта Inter (и, ако няма икони, Lucide). Питай, ако нещо изисква промяна извън визията.
6. Накрая потърси в кода останали стари hex/rgb цветове и ги замени с токени.

---

## Същност на стила
- **Тъмнина с топлина.** Фонът е почти черен с топъл подтон, никога неутрално сив.
- **Един акцент: червено `#D7000F`.** Използва се като светлина (ореоли, светене), не като голяма боядисана площ. Никакви други акцентни цветове.
- **Светлината идва отдолу и от центъра.** Hero, CTA и footer имат радиален червен ореол по долния ръб, а иконите имат ореол зад себе си.
- **Рамки, не сенки.** Картите се отделят с 1px полупрозрачна рамка и светъл горен ръб. Без тъмни drop shadows.
- **Тиха типография.** Големи заглавия с тегло 400 и отрицателен tracking. Силата идва от размера, не от удебеляване.

## Дизайн токени

```css
/* Шрифт: <link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500&display=swap" rel="stylesheet"> */
:root{
  /* Повърхности (от най-ниска към най-висока) */
  --bg-base:#0A0604;        /* фон на страницата */
  --bg-section:#120B07;     /* панели: hero, CTA, footer */
  --surface-card:#1A110C;   /* карти */
  --surface-raised:#24170F; /* hover на карта, плочки-икони, inputs */

  /* Рамки */
  --border-subtle:rgba(255,255,255,.08);
  --border-ember:rgba(215,0,15,.6);   /* активен/подчертан елемент */

  /* Акцент */
  --ember-300:#FF5C66;  /* светъл център на ореол, hover на линк */
  --ember-500:#D7000F;  /* основен акцент */
  --ember-600:#A3000B;  /* долен край на градиента на бутон, ядро на ореол */
  --ember-900:#3A0306;  /* където червеното потъва във фона; фон на бейджове */

  /* Текст */
  --text-primary:#F6F1EC;
  --text-secondary:#A39A93;
  --text-muted:#7A706A;     /* само кратък, не-критичен текст */
  --text-on-ember:#FFFFFF;

  /* Радиуси */
  --radius-sm:10px;   /* плочки-икони, бейджове, inputs */
  --radius-md:14px;   /* FAQ редове, малки карти */
  --radius-lg:20px;   /* стандартни карти */
  --radius-xl:28px;   /* hero, CTA, footer панели */
  --radius-pill:999px;/* всички бутони и етикети */

  /* Разстояния */
  --space-1:4px; --space-2:8px; --space-3:12px; --space-4:16px;
  --space-6:24px; --space-8:32px; --space-12:48px; --space-24:96px;

  /* Светлина */
  --glow-sm:0 0 24px rgba(215,0,15,.45);
  --glow-lg:0 0 80px rgba(215,0,15,.5);
  --inner-highlight:inset 0 1px 0 rgba(255,255,255,.08);
  --ember-glow:radial-gradient(ellipse at 50% 100%, var(--ember-300) 0%, var(--ember-500) 18%, var(--ember-600) 32%, var(--ember-900) 55%, transparent 75%);

  --font-sans:"Inter","SF Pro Display",system-ui,-apple-system,sans-serif;
}
```

**Tailwind (ако се ползва):** добави в `theme.extend` → `colors.ember {300,500,600,900}`, `colors.surface {base,section,card,raised}`, `borderRadius`, `boxShadow {glow-sm, glow-lg, inner-highlight}`, `fontFamily.sans` със същите стойности.

## Типография

| Стил | Размер / line-height | Тегло | Tracking | Къде |
|---|---|---|---|---|
| display-xl | 64px / 1.05 (мобилно ~40px) | 400 | -0.03em | Hero заглавие |
| display-l | 44px / 1.1 (мобилно ~32px) | 400 | -0.025em | Заглавия на секции |
| heading | 28px / 1.2 | 400 | -0.02em | Подсекции |
| card-title | 20px / 1.25 | 500 | -0.01em | Заглавия на карти |
| body | 15px / 1.6 | 400 | 0 | Основен текст |
| small | 13px / 1.5 | 400 | 0 | Описания, навигация |

## Компоненти (визуални правила)

- **Primary бутон:** pill; `background: linear-gradient(180deg, var(--ember-500), var(--ember-600))`; бял текст 14px/500; `box-shadow: var(--glow-sm), var(--inner-highlight)`; padding 10px 20px. Hover: по-силно светене.
- **Secondary бутон:** pill, прозрачен фон, `1px solid var(--border-subtle)`, текст `--text-primary`. Hover: `--surface-raised`.
- **Етикет над заглавие на секция:** pill, `label` стил, рамка `--border-subtle`, текст `--text-secondary`, центриран над заглавието (напр. „Pricing“, „FAQs“).
- **Карта:** `--surface-card`, `--radius-lg`, `1px solid var(--border-subtle)`, `box-shadow: var(--inner-highlight)`, padding `--space-6`. Hover: `--surface-raised` + `--border-ember`, transition 200ms.
- **Подчертана карта** (препоръчан план, избран елемент): `--border-ember` + `--glow-lg`, ореол в горния ъгъл, бейдж с фон `--ember-900` и текст `--ember-300`.
- **Икона в ореол:** плочка `--surface-raised` с `--radius-sm` или кръг, линейна икона (1.5px stroke) бяла или `--ember-300`, зад нея `--ember-glow` чрез `::before`.
- **FAQ ред (акордеон):** `--surface-card`, `--radius-md`, chevron вдясно. Отворен: `--border-ember` + `--glow-lg`, отговор в `--text-secondary`.
- **Inputs:** `--surface-raised`, `--radius-sm`, рамка `--border-subtle`. Focus: `--border-ember` + `--glow-sm`, без outline на браузъра (но с видим фокус).
- **Навигация:** прозрачна над hero; лого вляво; линкове `small` в `--text-secondary` (hover `--text-primary`); вдясно secondary + primary бутон.
- **Лента с лога:** монохромни лога в `--text-muted`, един ред под hero.
- **Ореол на панел:** `position:relative; overflow:hidden;` + `::before { content:""; position:absolute; inset:auto 0 -40% 0; height:80%; background:var(--ember-glow); pointer-events:none; z-index:0; }`. Съдържанието е с `position:relative; z-index:1`.

## Карта на компонентите

| Съществуващ елемент | Ember Glow модел |
|---|---|
| Header / навигация | Навигация (по-горе) |
| Hero | Панел `--radius-xl` + етикет + `display-xl` + primary/secondary бутон + ореол долу + лента с лога |
| Предимства / услуги | Етикет + `display-l` + грид от карти с „икона в ореол“ |
| Процес / стъпки | 3 карти в ред с икона в ореол и заглавие отдолу |
| Отзиви | Малки карти `--radius-md`; средната/активната е подчертана |
| Цени | 3 карти; препоръчаната е подчертана карта |
| FAQ | Акордеон от FAQ редове |
| Финален CTA | Панел `--radius-xl`, икона в ореол горе, заглавие, primary бутон, ореол |
| Footer | Панел `--radius-xl` с ореол долу; лого + слоган вляво, колони с линкове вдясно |
| Форми | Inputs + primary бутон |
| Всичко друго | Най-близкият модел (карта или панел); попитай при съмнение |

## Ред на прилагане
1. **Глобално:** токени, шрифт Inter, `body { background: var(--bg-base); color: var(--text-primary); font: 400 15px/1.6 var(--font-sans); }`.
2. **Базови елементи:** заглавия h1–h3, бутони, линкове (`--text-secondary`, hover `--ember-300`), inputs.
3. **Повърхности:** всяка „кутия“ става карта, hero/CTA/footer стават панели.
4. **Светлина:** ореоли **само на 4–6 места** (hero, икони на предимства, препоръчан план, отворен FAQ, CTA, footer). Повече разваля ефекта.
5. **Детайли:** етикети над заглавията, монохромни лога, линейни икони, hover/transition 200ms.
6. **Проверка:** виж по-долу.

## Layout
- Съдържание центрирано, max-width ~1120px, странични отстъпи 16px на мобилно.
- Между секциите `--space-24` (64px на мобилно); между заглавие на секция и съдържание `--space-8`.
- Gap в гридове `--space-4`; гридовете стават една колона под ~768px.

## Проверка (задължително преди да кажеш „готово“)
- [ ] Структурата и съдържанието са непроменени (само стилове/класове).
- [ ] Няма останали стари цветове (grep за hex/rgb извън токените).
- [ ] Само един акцентен цвят: `#D7000F` и неговите нюанси.
- [ ] Контраст: основният текст ≥4.5:1; текст никога върху най-яркото петно на ореол.
- [ ] Видим фокус на всички интерактивни елементи.
- [ ] Мобилно (≤390px): без хоризонтален скрол, заглавията намалени, гридовете в една колона.
- [ ] Ореолите са CSS градиенти (без изображения), с `pointer-events:none`.
- [ ] Билдът минава без грешки.
